Cambios respecto a la app actual

  • Subtítulo «Pendientes · Todas las listas» quitado de la primera pasada: no existe en el código. Título «Tareas» a secas.
  • Hoja de filtros por estado / «Aplicar» / «Restablecer» quitada (no existe). El filtro real es un menú por lista («Todas» + una por lista), en la cabecera.
  • «+» de cabecera quitado: el código tiene el botón flotante «Nueva tarea», visible solo si hay tareas (frames 1, 7 y 8). Moverlo a la cabecera es propuesta, Nuevo, y no se dibuja.
  • Nombre de grupo que navega quitado: la cabecera del grupo solo pliega. Para abrir la lista está «Listas» y el detalle.
  • Nuevo Skeleton (3) y sin conexión (5). Hoy el texto es «Cargando tareas…» y no hay banner.
  • Nuevo Deslizar para eliminar se dibuja como existe hoy, sin confirmación. Añadir confirmación sería Nuevo.
  • Confirmación de borrado Nuevo: decisión del usuario (P-19); hoy el borrado por swipe/papelera/botón no confirma.
  • Pull-to-refresh en todas las listas (no se dibuja).

Reglas de negocio

  • Grupos por lista: cabecera con chevron + nombre + color + contador (pendientes + completadas). Toda la cabecera pliega; no navega.
  • Dentro del grupo: pendientes y luego completadas tachadas. Fila: casilla + título + etiquetas de persona asignada (badge de color con nombre). Tocar la fila = editar.
  • Filtro por lista: «Todas» + una por lista. No hay filtro por estado.
  • Con lista filtrada: campo «Nueva tarea» (alta rápida) y «Editar»/«OK» (reordenar), solo con orden «Personalizado».
  • Deep link desde Inicio: despliega solo la lista pulsada.
  • Textos reales: «Sin tareas» / «Crea tu primera tarea y ponle una lista para tenerla a mano.»; con filtro «Esta lista no tiene tareas todavía.»; «Cargando tareas…»; botón «Nueva tarea».
  • Errores: de carga = mensaje del servidor + «Reintentar»; de acción = alerta «Aviso / OK».
  • Quitado por no existir: «Pendientes · Todas las listas», hoja de filtros por estado, «+» de cabecera como existente.

Conexiones

  • Llega desde: Inicio (tarjeta «Tareas pendientes», «Ver más» → frame 11) y barra de pestañas.
  • Sale a: tasks-form-tarea («Nueva tarea»), tasks-listas (segmento «Listas»), tasks-detalle-lista (desde «Listas»).
  • Por confirmar: ocultar o no el alta rápida mientras se reordena (frame 8).
