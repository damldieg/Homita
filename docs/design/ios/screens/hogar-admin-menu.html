Cambios respecto a la app actual

  • Cada una de las seis secciones gana un resumen de una línea («2 administradores», «1 pendiente») para no abrir cada una solo para saber el estado.
  • Iconos con color por tipo de sección (acento para gestión de permisos, verde para personas, ámbar para lo pendiente). El color sirve de pista, el texto manda.
  • Filas de 68 pt con toda la fila como gesto único (antes el chevron era la única señal). Área táctil amplia.
  • La cabecera usa «‹» con el nombre del hogar centrado, en vez del título de la sección; el título grande «Administración» queda pegado arriba.
  • Versión de miembro: solo Configuración y Administradores, en lectura. Las secciones de gestión se ocultan (no se deshabilitan).

Conexiones

  • Llega desde: HOGAR-01 («Administración»).
  • Lleva a: HOGAR-04 (Configuración), HOGAR-05 (Administradores), Miembros, Invitaciones, Accesos y Auditoría. Vuelve a HOGAR-01 con «‹».
