Cambios respecto a la app actual

  • La captura 52 muestra solo el menú de Administración, no esta lista. El contenido sale de docs/ios-funcional.md (4.6): hay que repetir la captura con la lista abierta.
  • Se separan «Con cuenta» y «Sin cuenta» en dos grupos. Hoy «Vinculada»/«Sin cuenta» va como texto suelto en cada fila.
  • Para un miembro sin permisos de admin, «+» no aparece (ni deshabilitado) y las filas no navegan a la hoja de edición.
  • El alta pasa a una hoja con Cancelar/Guardar. El tipo «mascota» no se ofrece para personas vinculadas a una cuenta (regla del README de Control iOS).
  • Estados vacío, error y sin conexión explícitos; la edición se desactiva sin conexión en lugar de fallar al guardar.
